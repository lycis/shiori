# Contributing to Shiori

Contributions are welcome. There is no special process:

1. Fork the repository.
2. Make your changes in a branch.
3. Open a pull request describing what you changed and why.

When contributing, please keep the following principles in mind:

- Write code that conforms to the **C23 standard**.
- Try to follow the existing coding style and conventions so that new code
  feels consistent with the rest of the project.
- Make sure the project still builds cleanly before submitting your pull
  request.

## AI-assisted contributions

Using AI tools while contributing to Shiori is permitted, but the contributor
remains responsible for everything they submit.

If AI assisted with your contribution:

- Review, understand, and test all generated or suggested changes.
- Ensure the code follows the project's conventions and contains no
  unnecessary or unrelated changes.
- Verify that you have the right to submit the resulting code, documentation,
  and other materials.
- Do not include private information, credentials, proprietary code, or other
  sensitive material in prompts or contributions.
- Briefly disclose substantial AI assistance in the pull request description.

Pull requests that the contributor cannot explain, maintain, or revise may be
declined. AI output should be treated as a suggestion, not as an authority or a
substitute for engineering judgment.

Thank you for helping improve Shiori.
